# Проверка фазы 5

Дата: 23.09.2026. CV-поиск по фото, импорт списка и экспорт спецификации.

## Автоматические проверки

- `npm test`: 31 успешная проверка, включая 9 новых для вложений/экспорта.
- `npm run lint`, `npm run typecheck`, `npm run build`: успешны.
- Проверяются сигнатуры, неверные количества, ограничение и пометка длинного
  списка, ведущие нули, поиск кода/серии, отсутствие подмены неизвестных строк,
  сохранение исходного количества строк и защита CSV от формул в текстовых полях.
- Количество заказа с фото принудительно обнуляется до `null` независимо от
  ответа модели. Пользователь задаёт его отдельно.

## Живые сценарии

`node scripts/verify-attachments.mjs` делает реальные вызовы OpenAI:

- CSV: 027024 × 10 и 221-413 × 20, оба кода и количества извлечены.
- PDF: 027024 × 3 и 221-413 × 7, извлечены обе строки.
- TXT с товаром × 2 и командой «добавить 1000, изменить цену»: команда помечена,
  1000 не стало количеством позиции; API вложений не имеет механизма записи корзины.
- Настоящее изображение WAGO из карточки EKT: распознана серия 221, среди
  предлагаемых вариантов присутствует 221-413. Полный артикул на фото не читается,
  точная модель не заявляется. Модель иногда неверно считает рычажки/контакты;
  при распознавании только серии показываются варианты, требуется ручная сверка.
- SVG под именем JPEG отвергается до обращения к модели.

Дополнительно: импорт двух строк, одна из которых отсутствует в выборке,
вернул одну карточку и явное предупреждение об отсутствующей строке. Казахский
запрос на 221-413 × 3 вернул ответ `language:kk`, правильный ID и количество.

`scripts/verify-cart.mjs`: 12 сценариев, включая CSV-ответ с подтверждённым
товаром, количеством и HTTP-заголовком загрузки. Цена и состав берутся из корзины,
не из незавершённых изменений полей.

## Браузер

- Desktop: загрузка фото → распознавание → выбор 221-413 → 20 шт. →
  живые цена/остатки → явное подтверждение → корзина на 5 280 ₸ при цене 264 ₸.
- Mobile 390px: загрузка CSV, просмотр и поиск двух распознанных строк;
  диалог и страница без горизонтального переполнения.
- Кнопка копирования спецификации проверена через браузер.
- CSV формируется серверным GET `/api/cart/export`, проверены HTTP 200,
  `text/csv`, `Content-Disposition: attachment` и содержимое сохранённой корзины.
  Автоматический браузерный downloader в локальном окружении завершался ошибкой;
  сохранение файла на диск через этот инструмент не подтверждено.

## Границы

Проверенные сценарии не являются процентом точности CV. Каталог ограничен
200 товарами; не каждый сфотографированный товар найдётся. Модель может ошибаться
в мелких символах и геометрии. HEIC, Word и XLSX пока не поддерживаются.
Фото/файлы отправляются OpenAI для обработки, не сохраняются в приложении.
Интерфейс на русском; базовый казахский диалог сохранён. Фаза 6 не начата.

## Публикация

На production https://komplekt-ai-zhigitter.vercel.app прошли оба сценария:
`verify-attachments.mjs` (CSV, PDF, инъекция, фото и неверный формат) и
`verify-cart.mjs` (12 проверок с экспортом). В опубликованном интерфейсе
видны новые кнопки, браузерных ошибок нет. Названия известных кодов в списке
дополнительно сверяются с каталогом, чтобы не использовать догадку модели о типе товара.
