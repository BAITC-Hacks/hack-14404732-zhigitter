# План прототипа «Комплект AI»

## Проблема

При покупке электротехнических товаров клиенту приходится отдельно уточнять
характеристики, наличие, возможные аналоги и условия покупки. Это занимает
время и может привести к ошибке при выборе позиции.

## Решение

«Комплект AI» — чат-помощник для ekt.kz. Он помогает составить заказ по
текстовому запросу или спецификации, используя данные каталога и остатков.

## Что будет реализовано в прототипе

- Поиск товара по артикулу и названию.
- Карточка товара: цена, технические характеристики, остаток и сертификат,
  если он доступен.
- Поиск аналогов для отсутствующей позиции с причиной рекомендации.
- Ответы на вопросы об оплате, доставке и минимальной партии.
- Проверка, что количество в корзине не превышает остаток.
- Явное подтверждение перед изменением корзины.
- Ссылка на актуальную корзину после добавления.

## Важное правило безопасности

Ассистент не меняет корзину по обычному запросу вроде «хочу этот товар».
Изменение происходит только после отдельного явного подтверждения пользователя.

## План демонстрации

1. Пользователь запрашивает конкретный товар.
2. Ассистент показывает реальные данные из каталога и наличие.
3. Для отсутствующей позиции показывает вариант замены и различия.
4. Пользователь подтверждает выбранные товары.
5. Ассистент обновляет корзину и показывает ссылку на неё.

## Ближайшие шаги

2. Подключить получение товаров из API ekt.kz.
3. Реализовать сценарий предложения и подтверждения корзины.
4. Проверить обязательные требования кейса и подготовить финальный README.
