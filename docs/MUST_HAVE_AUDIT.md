## Дополнительные пункты задания

- Фото JPEG/PNG/WebP, PDF, Word DOCX, Excel XLSX, TXT/CSV: реализованы.
  Старые бинарные DOC/XLS требуют сохранения в современный формат.
- Office: до 3 МБ входного файла, 8 МБ распакованного содержимого, 500 ZIP-записей,
  5 Excel-листов, 1000 строк, 16 000 символов текста. Формулы требуют экспорта
  значениями; внешние связи, макросы и вложенные программы не исполняются.
- За один подбор — до 4 позиций, требуется проверка распознанного списка.
- Desktop/mobile проверены. Базовый казахский сохранён; интерфейс преимущественно русский.
- Контекст диалога — в памяти вкладки, авторизации и постоянной истории нет.
- Консультация по совместимости формирует черновик для менеджера, но не отправляет его.

## Интеграция с реальным EKT

Выданные партнёром адреса API относятся к чтению каталога и деталей товаров.
Для реального внедрения нужны документированный API корзины, механизм сессии
покупателя и доступ команды EKT для установки виджета. Изменять production EKT
через недокументированные запросы вместо такой интеграции прототип не пытается.
Текущий интерфейс повторяет привычную структуру магазина EKT с собственным
брендом и видимой маркировкой прототипа.

Ссылки источников: [EKT](https://ekt.kz/),
[оплата и доставка](https://ekt.kz/checkout-delivery/).
Кратность 1 также обнаружена в публичной кнопке покупки карточек 027024 и 027228
в атрибуте data-kratnost. Во всей проверенной выборке KRATNOST_MIN: 1, 5 или 10.
