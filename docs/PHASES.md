# Этапы реализации

Общий бюджет: 3 часа 30 минут активной разработки. После каждого этапа
команда показывает результат пользователю и ждёт разрешения продолжать.
Ожидание действий и подтверждений пользователя учитывается отдельно.

Текущий статус: реализованы фазы 1–7 в объёме прототипа. По запросу пользователя
в финальный этап включены надёжность AI, Word/Excel, аудит must-have,
интерфейс в стиле EKT, аватар и помощь с возражениями. Реальное внедрение
в EKT и неподтверждённые условия поставщика описаны в MUST_HAVE_AUDIT.md.

| Этап                     | Минуты от начала | Результат                                                           |
| ------------------------ | ---------------- | ------------------------------------------------------------------- |
| 1. Основа и доступы      | 0–15             | Стартовый экран, конфигурация, проверка запуска и размещения        |
| 2. Каталог               | 15–45            | До 200 товаров, поиск, карточки, источники и остатки                |
| 3. Чат и подбор          | 45–85            | Обработка запроса, объяснимые аналоги, противоречия                 |
| 4. Предложение и корзина | 85–125           | Варианты комплектации, суммы, подтверждение, сохранение корзины     |
| 5. Вложения и удобство   | 125–155          | Поиск по фото/маркировке, импорт списка, экспорт, базовый казахский |
| 6. Уточнения и сравнение | 155–190          | Два товара рядом, уточнение параметров, читаемость и проверки         |
| 7. Сдача                 | 190–210          | Проверка опубликованной версии, README и демонстрация               |

Дополнение к финальной фазе: сравнение цен внутри диалога и трёхминутный
сценарий в DEMO_SCRIPT.md.

Следующий этап не запускается автоматически. Факт наличия API-ключа
не является разрешением перейти к следующему этапу.

Полная локализация интерфейса отложена; Word DOCX и Excel XLSX добавлены;
базовые ответы на казахском сохраняются. Поиск по фото должен предлагать
кандидатов из каталога, а не утверждать точную модель по внешнему виду.
Подтверждение корзины, проверка цен и остатков и финальная
проверка сохраняются. Содержательные коммиты отправляются на GitHub не реже
часа во время активной разработки и по завершении этапов.
