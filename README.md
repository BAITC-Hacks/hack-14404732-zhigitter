# Комплект AI

Прототип ИИ-помощника для сайта ekt.kz. Он помогает покупателю подобрать
электротехнические товары, проверить наличие, увидеть объяснимые замены и
собрать корзину только после явного подтверждения.

## Статус

Проект команды **Zhigitter** находится в разработке в рамках HackAlem AI.

**Фаза 1 — основа приложения.** Подготовлены адаптивный стартовый экран,
выбор города, редактируемый черновик запроса, примеры запросов и маршрут
проверки работоспособности сервера. Отправка запроса намеренно отключена:
каталог, AI-подбор и корзина пока не реализованы. Стартовый экран не выдаёт
демонстрационные цены и остатки за реальные данные.

Опубликованная версия: **https://komplekt-ai-zhigitter.vercel.app**.

Проверки фазы 1: production-сборка, ESLint и TypeScript проходят; стартовая
страница проверена в браузере на компьютере и при ширине 390 px. Примеры
заполняют черновик, выбор города работает, горизонтальной прокрутки нет.
Опубликованная страница и `/api/health` доступны. Доступ к API ekt.kz
проверен отдельно, подключение каталога к интерфейсу запланировано на фазу 2.
OpenAI API-ключ на момент завершения фазы 1 ещё не добавлен.

## Технологии

Next.js App Router, React, TypeScript, Tailwind CSS, Lucide. Приложение
подготовлено для размещения на Vercel; база данных в фазе 1 не требуется.

## Локальный запуск

Требуется Node.js 22 или новее. Проверено окружение Node.js 24.

```bash
npm ci
```

Создайте `.env.local` по образцу `.env.example`. Секреты заполняются только
локально или в настройках Vercel и не коммитятся. Стартовая страница работает
без ключей. Будущим интеграциям потребуются:

| Переменная | Назначение |
| --- | --- |
| `OPENAI_API_KEY` | API-ключ проекта OpenAI |
| `OPENAI_MODEL` | Модель, по умолчанию `gpt-4.1-mini` |
| `EKT_API_BASE_URL` | Базовый адрес API каталога |
| `EKT_API_USERNAME`, `EKT_API_PASSWORD` | Доступ к API, выданный партнёром |
| `CART_SIGNING_SECRET` | Случайный секрет длиной не менее 32 символов |

```bash
npm run dev
```

Откройте `http://localhost:3000`. Кнопки примеров заполняют редактируемый
черновик. Выбор города меняется в текущей вкладке. Черновик и город пока
не сохраняются после перезагрузки.

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
npm run env:check
```

`env:check` выводит только наличие переменных, без их значений. Он возвращает
ненулевой код при незаполненных настройках, но не проверяет валидность ключей
и не обращается к внешним API.

`GET /api/health` отвечает `status: "ok"` и `integrations: "not_connected"`.
Успешный ответ подтверждает работу приложения, а не готовность AI или каталога.

## Размещение

Для Vercel используйте пресет **Next.js**, корневую папку репозитория и команду
сборки `npm run build`. Переменные окружения добавляются отдельно в настройках
проекта. `.env.local` исключён и из Git, и из загрузки файлов в Vercel.

Первое размещение выполнено через Vercel CLI. Автопубликация по push пока
не подключена: Vercel не смог связать репозиторий организации с проектом.
До подключения Git-интеграции обновления публикуются командой
`npx vercel deploy --prod` из привязанного рабочего каталога.

## Источники и границы прототипа

Планируемый источник каталога, изображений и остатков — API ekt.kz.
Начальная выборка следующей фазы — до 200 товаров. Корзина будет собственной,
без оформления и резервирования в ekt.kz. Платёжные данные не запрашиваются.

## Планируемый основной сценарий

1. Покупатель отправляет запрос или список нужных товаров.
2. Ассистент ищет позиции в каталоге ekt.kz и показывает характеристики,
   цену и наличие.
3. Если товара нет, ассистент предлагает аналог и объясняет различия.
4. Перед добавлением показывается состав будущей корзины.
5. Корзина меняется только после явного подтверждения покупателя.
